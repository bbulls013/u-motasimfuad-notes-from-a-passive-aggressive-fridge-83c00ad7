Entry for the make.fun bounty [Notes From a Passive-Aggressive Fridge](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7): one funny passive-aggressive note a smart fridge leaves for its owner, judged head to head by the house judge.

## Run

```sh
python3 main.py
```

The program writes its single note to `/output/entry.txt` (falling back to `./output/entry.txt` when `/output` does not exist). It is deterministic: every run writes the same bytes.
